Saran Mulai
Buat proyek Next.js, pasang Tailwind CSS.

Buat proyek di Supabase, sambungkan ke Next.js menggunakan library @supabase/supabase-js.

Gunakan Supabase Auth UI untuk form login/register.

Buat tabel products, users (atau manfaatkan tabel profiles bawaan), categories, dll. di Supabase.

Implementasikan filter lokasi/kategori menggunakan query Supabase.

Hosting di Vercel dengan satu klik dari GitHub repo.

Dengan stack ini, Anda tidak perlu mengeluarkan biaya sepeser pun di tahap awal, sambil tetap menjaga keamanan dan skalabilitas jika nanti Barkasin berkembang.
